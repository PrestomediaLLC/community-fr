# Centre de Support Communautaire

Bienvenue sur le forum public de support communautaire pour les applications de [Prestomedia](https://prestomedia.com/fr) ! 

Cet espace est dédié aux échanges entre utilisateurs, aux demandes de fonctionnalités et aux questions-réponses générales. Veuillez noter qu'*il s'agit d'un forum communautaire public*.



## 📱 Sélectionnez votre application

Pour poser une question, signaler un problème ou suggérer une idée, cliquez sur la catégorie de discussion de votre application ci-dessous :

* 📝 [**Free Text Editor**](https://github.com/PrestomediaLLC/community-fr/discussions/categories/free-text-editor-com)
* 📊 [**Pro Diagrams**](https://github.com/PrestomediaLLC/community-fr/discussions/categories/prodiagrams-com) (bientôt disponible)
* 📊 [**Free Diagrams**](https://github.com/PrestomediaLLC/community-fr/discussions/categories/freediagrams-com) (bientôt disponible)
* 📊 [**Team Matcher**](https://github.com/PrestomediaLLC/community-fr/discussions/categories/team-matcher-com) (bientôt disponible)

*(Lorsque vous cliquez sur **« New discussion »** dans une catégorie, un formulaire préformaté vous guidera pour publier votre message.)*



## 📋 Règles de la communauté

Avant de publier, veuillez garder à l'esprit les points suivants :

1. **Cherchez d'abord :** Consultez les discussions existantes dans la catégorie de votre application ; votre question ou demande a peut-être déjà trouvé une réponse.
2. **Protégez votre vie privée :** **Ne publiez jamais d'informations personnelles privées**, d'adresses e-mail, de mots de passe, de clés de licence ou de données financières sensibles. Toutes les publications sont entièrement publiques.
3. **Soyez respectueux :** Traitez les autres membres de la communauté avec bienveillance. Des discussions courtoises et constructives nous aident à créer de meilleures applications pour tous !
